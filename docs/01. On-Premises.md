
# 01. On-Premises 환경 구축

## 1. 프로젝트 목적

VMware Workstation을 활용하여 Ubuntu 24.04 기반 WEB/WAS/DB 3-Tier 인프라를 구축하고, 이후 AWS 마이그레이션을 위한 기존 운영 환경을 준비한다.

## 2. 서버 구성

| 구분 | Hostname | 초기 확인 IP | OS | 역할 |
|---|---|---|---|---|
| WEB | web01 | 192.168.111.147 | Ubuntu 24.04 | Apache HTTP Server |
| WAS | was01 | 192.168.111.148 | Ubuntu 24.04 | Spring Boot / Tomcat |
| DB | db01 | 192.168.111.149 | Ubuntu 24.04 | MySQL |

- 가상화 환경: VMware Workstation
- 네트워크 방식: NAT
- 네트워크 대역: 192.168.111.0/24
- 기본 게이트웨이: 192.168.111.2

※ IP는 최초 점검 시 확인한 값이며, 고정 IP 설정 후 최종 주소와 일치하는지 확인한다.

## 3. 네트워크 기본 점검

### 3.1 서버 이름 확인

`hostname`

현재 접속한 서버의 호스트 이름을 확인한다.

### 3.2 네트워크 인터페이스 확인

`ip -br addr`

네트워크 인터페이스의 상태와 할당된 IP 주소를 확인한다.

### 3.3 라우팅 테이블 확인

`ip route`

기본 게이트웨이와 로컬 네트워크의 라우팅 경로를 확인한다.

### 3.4 서버 간 통신 검증

- WEB → WAS
- WEB → DB
- WAS → DB
- 역방향 통신

검증 명령어 예시:

`ping -c 3 192.168.111.148`

ICMP 응답을 통해 서버 간 IP 통신 가능 여부를 확인한다.

### 3.5 인터넷 및 DNS 점검

- `ping -c 3 8.8.8.8`
- `getent hosts google.com`

외부 IP 연결과 DNS 이름 해석이 가능한지 확인한다.

## 4. Ubuntu 기본 보안 설정

### 4.1 패키지 업데이트

- `sudo apt update`
- `sudo apt upgrade -y`

설치된 패키지를 최신 보안 업데이트 상태로 유지한다.

### 4.2 사용자 권한 확인

- `whoami`
- `id`
- `sudo -l`

현재 사용자 및 관리자 권한을 확인한다.

### 4.3 SSH 서비스 확인

- `sudo systemctl status ssh`
- `sudo ss -tlnp`

SSH 서비스의 실행 상태와 리스닝 포트를 확인한다.

### 4.4 UFW 방화벽 기본 정책

- 기본 인바운드: Deny
- 기본 아웃바운드: Allow
- SSH: 실습용 관리 네트워크에서 TCP 22 허용

설정 예시:

- `sudo ufw default deny incoming`
- `sudo ufw default allow outgoing`
- `sudo ufw allow from 192.168.111.0/24 to any port 22 proto tcp`
- `sudo ufw enable`

설정 확인:

`sudo ufw status verbose`

SSH 접근을 허용한 후 방화벽을 활성화하여 원격 접속이 차단되지 않도록 한다.

### 4.5 리스닝 포트 확인

`sudo ss -tulpen`

실행 중인 서비스가 사용하는 TCP/UDP 포트를 확인한다.

## 5. 계층별 포트 설계

| 서버 | 포트 | 접근 대상 |
|---|---|---|
| WEB | 80/TCP | 사용자 |
| WAS | 8080/TCP | WEB |
| DB | 3306/TCP | WAS |
| 관리 | 22/TCP | 관리자 |

현재 단계에서는 SSH 기본 접근만 설정했으며, HTTP/Tomcat/MySQL 포트는 서비스 설치 시 필요한 출발지에 한해 추가 허용한다.

## 6. 학습한 핵심 개념

- NAT: 사설 네트워크에서 외부 네트워크로 통신할 수 있도록 주소를 변환하는 기술
- DHCP: IP 주소와 네트워크 정보를 자동 할당하는 기술
- Routing Table: 목적지별 패킷 전달 경로를 결정하는 정보
- SSH: 서버에 암호화된 원격 접속을 제공하는 프로토콜
- UFW: Ubuntu에서 방화벽 정책을 관리하는 도구
- Least Privilege: 필요한 사용자에게 필요한 권한만 부여하는 보안 원칙
